## 3 关键技术裁决（架构师实测核验，8 项）

| 编号 | 裁决 |
|---|---|
| Q-01 持久化 | `import { preferences } from '@kit.ArkData'`；`getPreferencesSync` + `getSync/hasSync` 启动同步读，`put/flush/delete/clear` 运行异步写；关系型存储不启用 |
| Q-02 路由 | `@ohos.router`（Kit 化 `@kit.ArkUI`），单栈 `pushUrl/back`；10 个页面文件命名锁定；平板用 `mediaquery` + `GridRow/GridCol` |
| Q-03 图表 | ArkUI Canvas 自绘，零第三方/零联网/零静态图；真实日志数组驱动 |
| Q-04 定时器 | 全局 `setInterval/clearInterval` 由 `TimerHost` 单例封装，绑定 UIAbility 六钩子；页面只订阅/取消订阅 |
| Q-05 导出 | 沙箱目录导出可行（保留 P1 收窄范围）；跨应用系统分享列 P2 |
| Q-10 规则冲突 | **锁定**：确定性排序 `priority↑→createdAt↑→id`，先执行者优先写入，同设备同参数冲突记 `SKIPPED_CONFLICT`，禁止隐式覆盖；落成 `WriteGuard` + B-1~B-8 护栏 |
| Q-12 日志 | 四类上限 1000/1000/2000/500（合计 ≤4500），FIFO 淘汰，三级重置粒度 |
| Q-15 异常设备 | 提供 DeviceDetail「模拟/调试」显式置位入口，必须经 `DeviceService` 并写日志 |

**两条真实性红线**（SC-02 核心）：`RuleExecutionLog` 仅允许 `RuleEngine` 写入；冲突不得隐式覆盖。
