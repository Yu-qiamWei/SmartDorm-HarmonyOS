- 性质：阶段二「基础工程与 UI 开发」的**替换式接入面**汇总。阶段三/四只替换实现，
  不改页面与组件（NFR-06 页面与逻辑分离、NFR-11 Mock 可注入）。
- 纪律：所有占位方法**签名齐全、返回带明确 `ResultCode` 的安全默认值、不抛异常、
  不返回 `undefined`、不写业务日志、不改领域内存态**，并带 `TODO(ST-03/ST-04)` 说明；
  绝不产生「看起来像真执行」的效果。

## 3 `Stage2ServiceFacade` 占位方法一览（页面实际调用）

| 方法 | 对应 MI / 需求 | 安全默认值 |
| --- | --- | --- |
| `setPower / setParam / addDevice / removeDevice` | MI-02~05 | id/名称校验后 `NO_CHANGE`；越界 `INVALID_PARAM`；空 id `NOT_FOUND` |
| `setDeviceStatus / setOnline` | MI-06 / Q-15 | 空 id `NOT_FOUND`，否则 `NO_CHANGE`（模拟诊断区调用） |
| `getEnvironmentSnapshot / adjustEnvironment` | MI-07/08 | 默认环境初值；传感器越界 `INVALID_PARAM`，否则 `NO_CHANGE` |
| `createRule / updateRule / removeRule / toggleRule` | MI-11 | 表单校验后 `NO_CHANGE`，原样回传草稿 |
| `evaluateRules` | MI-12 | 完整 `RuleEvaluationReport`，`newLogs: []`，`skipReason` 写明占位 |
| `applyScene / createScene / updateScene / removeScene` | MI-14 / FR-05 | 完整 `SceneApplyReport`（0 项）或 `NO_CHANGE` |
| `queryLogs` | MI-13 | 空数组（禁止预置演示日志） |
| `buildLineModel / buildBarModel / successRate` | FR-06 | 空 `series` / 空 `bars`（标题中的条数来自真实日志长度）；`0/0 = 0` |
| `buildLiveEnvironmentBarModel` | FR-06-03 | 由**真实 `EnvironmentData` 当前读数**构造 5 根柱，供阶段二图表真实绘制 |
| `exportState / updateSettings / resetData / flush` | FR-07 | `NO_CHANGE` 并回传安全数据，不写内存态 |

> 页面每个可见交互控件都调用上述方法之一（或真实 `router` 导航 / `ConfirmDialog` 二次确认 /
> 页面局部 `@State` 更新），并用 `ToastHost.showResult()` 把 `CommandResult.message`
> （含成功 / 无变更 / 失败原因码语义）以 `promptAction.showToast` 明确反馈；**无空 `onClick`**。
